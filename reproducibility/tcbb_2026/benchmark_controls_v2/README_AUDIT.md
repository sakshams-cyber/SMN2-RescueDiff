# Risdiplam and Branaplam 2 x 100 Audit Release

This is the complete local Module 4 v2 benchmark-control run for risdiplam and branaplam, including target scores, 200 decoy scores, selectivity tables, configurations, logs, prepared ligands, and poses.

The two controls were held out from model training. Their target scores can be used as descriptive reference baselines within this Vina protocol. Their decoy scores used the same historical fixed target box applied to independently positioned HuRDA receptors. They are therefore retained for provenance but withdrawn from selectivity inference. They must not be compared with generated molecules as evidence of clinical superiority.
